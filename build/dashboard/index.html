Fault Tolerance & Failover Architecture Verification

1

Configurable Replication

Each uploaded file is divided into 64KB chunks and replicated across configurable independent storage node processes.

2

Heartbeat & Failure Detection

Storage nodes stream periodic TCP heartbeats. If a node fails for > 5 seconds, it is marked OFFLINE.

3

Seamless Failover Reads

When reading a file whose primary replica is down, the coordinator transparently falls back to healthy surviving replicas.

4

Automatic Re-Replication

Background health monitor identifies under-replicated chunks and copies them to available healthy nodes.
